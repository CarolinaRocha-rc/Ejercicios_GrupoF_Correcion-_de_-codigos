# Ejercicios_GrupoF_Correcion-_de_-codigos
Este repositorio contiene una aplicación de consola desarrollada en C++ que implementa un algoritmo de búsqueda lineal para consultar calificaciones estudiantiles mediante el uso de arreglos paralelos. El proyecto destaca por su enfoque en la programación estructurada y el manejo seguro de memoria, optimizando el flujo de control con un bucle estrictamente acotado a los límites de los arreglos (i < 3) e interrupciones eficientes (break) al encontrar coincidencias. Es un recurso ideal para entornos académicos que buscan ejemplificar la manipulación limpia de cadenas, la entrada/salida de datos estándar (<iostream>) y la prevención de errores de desbordamiento (out-of-bounds).
